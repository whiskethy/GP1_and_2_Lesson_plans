# Setting Up GitHub

Version control is how programmers keep track of the work they do. Every time you save a change, you get a copy marked with what changed and when, so you can always go back. It is a save system for code.

GitHub is the website where those saves live. You can look back at anything you have saved, and other people can get a copy of your code to use or work on. GitHub is a professional tool. Companies like Google, NVIDIA, and Epic Games run full projects on it, and knowing your way around it is expected of a working programmer.

From today on, GitHub is how you turn in every project in this class.

## Part 1: Make your account

Mirrors Nick's Google doc (the live version is the Google flow; this copy is the plan layer).

1. Go to **github.com** and click **Sign up** in the top right.

[SCREENSHOT: the github.com homepage with the Sign up button visible in the top right corner. The headless browser is blocked by GitHub's bot wall, so capture on your own machine.]

2. **Already have a GitHub account?** Use it. You can link your school email to it later. Do not make a second account.
3. Click **Continue with Google** and sign in with your school Google account (the @chicagotechacademy.org one).

[SCREENSHOT: the GitHub signup page showing the Continue with Google button. Capture on your own machine - GitHub's bot wall blocked the headless browser.]

[SCREENSHOT: the Google account chooser showing the school account to click.]

4. GitHub asks about email updates. Uncheck the box if you do not want to hear from GitHub, then click Continue. GitHub may skip this page on the Google flow - if it never shows up, that's normal, go to the next step.

[SCREENSHOT: the email preferences page, if it appears in the flow - confirm on your own walkthrough.]

5. Now the username. Read the rules below BEFORE you type anything.

**Username rules**

- Do NOT use your real name. No first name, no last name, no nickname your friends call you.
- School appropriate.
- Other than that, it is yours. Pick something you would be fine seeing in a video game credits list.

Why no name: your username is public. Everyone in the org sees it, so do people who find you on GitHub outside school.

[SCREENSHOT: the username checker page showing a taken name in red and an available name in green.]

6. Solve the wizard steps (it checks you are human). When you see your new dashboard, you are done with this part.

[SCREENSHOT: the new GitHub dashboard a student lands on. Capture on your own machine.]

7. Double-check the email is confirmed. GitHub: profile picture top right → **Settings** → **Emails**; the school email should show **Verified**. If it does not, open your school Gmail, find the verify-link email from GitHub (check spam), and click it. A not-verified email blocks basic GitHub tasks later, so make sure it flips now.

**Already have a GitHub account?** Use it. You can link your school email to it later. Do not make a second account.
