# GP1 Q1 Day 04 — File Systems

**Date:** Thu 8/28 · **Unit:** 1 · **Chunk:** 4

## Learning Target

Explain how a computer stores and organizes files.

**Standards:** CSTA 3A-CS-02 · ACT WME 402, IDT 403

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review | Name two parts of a computer and what they do. |
| 2 | Review | (see Review 1 above) |
| 3 | Preview | How do you think a computer organizes all its files? |

## Exit Ticket

1. What is a file path? 2. Why does a computer use a hierarchical file system?

**Mastery Criteria:** Correctly explains file paths and hierarchical organization.

## Agenda

1. Do Now review (5 min)
2. File systems lesson (25 min)
3. Guided practice: navigating file paths (20 min)
4. Independent practice (17 min)
5. Wrap up (5 min)

## Differentiation & Accommodations

- **Engagement:** Students navigate their own file system
- **Representation:** Visual folder tree diagram
- **Action & Expression:** Written or demonstrated exit ticket
- **Accommodations:** Printed file tree reference
- **Student Voice:** Students explore their own computer's file system
