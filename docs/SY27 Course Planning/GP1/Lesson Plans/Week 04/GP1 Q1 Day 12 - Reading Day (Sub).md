# GP1 Q1 Day 12 — Reading Day (Sub)

**Date:** Mon 9/14 · **Unit:** 2 · **Chunk:** reading

> **Sub coverage.** Nick is out. No new instruction. Students read independently and complete the article assignment.

## Learning Target

Read and summarize key ideas from the game engine history article. Identify what a game engine does and why developers use them.

**Standards:** CSTA 3A-CS-01 · ACT WME 402, IDT 403

**Performance Task Connection:** The role research one-pager is the Unit 2 deliverable. Understanding what game engines do and why developers use them is required to write that comparison.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review | Name two things a game engine does for a developer. |
| 2 | Preview | What era do you think the first game engine appeared? |

## Exit Ticket

1. What was the first game engine as we understand the term today? 2. Name one game that reused code from an earlier game. 3. Why do developers use game engines instead of building from scratch?

**Mastery Criteria:** Identifies key ideas from the reading (first engine, code reuse, why engines matter). Completes the article assignment.

## Agenda

1. Do Now (5 min)
2. Independent reading: "Game Engines: All You Need to Know Article" (35 min)
3. Wrap up: exit ticket (8 min)
