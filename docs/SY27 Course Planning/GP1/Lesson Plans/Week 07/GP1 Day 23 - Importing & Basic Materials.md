# GP1 - Importing & Basic Materials (Day 23)

**Date:** Tue 10/6 · **Unit:** 3 · **Chunks:** 6 + 8

> Moved from Mon 10/5 (Day 22 ran as amnesty/catch-up instead — see [[GP1 Day 22 - Amnesty & Catch-Up]]). This file is otherwise as built.

## Learning Target

Import an FBX asset into Unreal, organize files in the Content Browser, create a basic material, and apply it to an object.

**Standards:** CSTA 3A-CS-01 · ACT WME 402

**Performance Task Connection:** Importing assets and applying materials are required for the level layout practical (Chunk 9). Students who cannot import or organize assets will produce broken or unstyled levels.

**Do Now** (retrieval, not a cold open)

| # | Type | Question |
|---|---------|----------|
| 1 | Review | What are the three transforms every object has? |
| 2 | Review | What color is the X axis in Unreal? What does dragging the red arrow do? |
| 3 | Preview | You can move, rotate, and scale an object. But how would you change what it looks like? |

**Agenda**

1. Do Now review (5 min)
2. EdPuzzle Video 08: Importing & Basic Materials (approx. 16-22 min with pauses)
3. Guided practice: import the ring asset, create folders, create a material, apply it (20 min)
4. Independent: opacity, emissive, and challenge tasks (15 min)
5. Wrap-up + exit ticket (7 min)

**Exit ticket**

1. What do the prefixes SM_ and M_ stand for in Unreal naming conventions?
2. What is the difference between base color and emissive color in a material?
3. What does the Blend Mode need to be set to for opacity to work?

**Exit ticket mastery criteria:** Correctly identifies SM_ as Static Mesh and M_ as Material, explains that base color is the surface color while emissive is light the object emits, and states that Blend Mode must be Translucent for opacity to work.

## Differentiation & Accommodations

- **Engagement:** Importing a real asset (the ring) that will be used in upcoming Blueprint lessons gives students ownership. Materials are immediately visual.
- **Representation:** Video provides step-by-step visual demo. Folder structure diagram on the board (Content → Meshes, Materials, Blueprints). Naming convention reference card (SM_, M_, BP_).
- **Action & Expression:** Exit ticket written or verbal. Students choose their own material colors and opacity levels.
- **Accommodations:** Printed step list for importing and material creation. Extended time. Pair-programming for students struggling with file navigation.
- **Student Voice:** Students choose their own material colors and opacity levels.
