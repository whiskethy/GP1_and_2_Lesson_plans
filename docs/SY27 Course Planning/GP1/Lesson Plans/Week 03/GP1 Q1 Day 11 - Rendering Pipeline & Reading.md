# GP1 Q1 Day 11 — Rendering Pipeline

**Date:** Thu 9/10 · **Unit:** 2 · **Chunk:** 10

## Learning Target

Describe the render loop and trace the path from game data to pixels on screen.

**Standards:** CSTA 3A-CS-01, 3A-CS-02 · ACT WME 402, IDT 403

**Performance Task Connection:** The render loop is the core cycle that drives every game. Understanding it is prerequisite for troubleshooting viewport and performance issues in Unit 3 and for the engine comparison brief in Chunk 3.

## Exit Ticket

1. List the stages of the render loop in order. 2. Pick one stage and explain what happens there and why it matters.

**Mastery Criteria:** Correctly lists render loop stages in order and explains at least one stage in their own words.
