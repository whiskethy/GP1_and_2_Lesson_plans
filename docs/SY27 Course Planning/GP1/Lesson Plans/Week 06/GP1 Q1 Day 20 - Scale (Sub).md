# GP1 Q1 Day 20 — Scale (Sub)

**Date:** Wed 9/30 · **Unit:** 3 · **Chunk:** 3 (scale)

## Learning Target

Use Unreal's Scale tool to resize objects, and explain the difference between uniform and non-uniform scaling.

**Standards:** CSTA 3A-CS-01 · ACT G 406, G 407, WME 402

**Performance Task Connection:** Scale is required for the level layout practical (Chunk 9). Objects need correct proportions.

**Agenda for sub**

> 3. Independent practice: scale challenges in Unreal — uniform and non-uniform scaling, reset to default (15 min)

> The sub does NOT need to teach content — the video and the worksheet carry all instruction. Collect worksheets at the end of the period. If a student is stuck for more than five minutes, tell them to rewind the video section or check the worksheet's axis diagram.

**Exit ticket** (on paper)

1. An object is scaled to X=1, Y=1, Z=1. You change X to 3. What happened to the object?
2. What is the difference between uniform and non-uniform scaling?
3. What is the Scale tool keyboard shortcut, and what does the white center cube do when you drag it?

**Exit ticket mastery criteria:** Explains that X=3 makes the object three times as wide along X, states that uniform scaling changes all axes equally while non-uniform changes them independently, and identifies the R key for Scale tool with the white cube scaling uniformly.
