## Structure

1. Do Now review (5 min)
2. Finish-the-test-assignment catch-up (20 min, the day's spine): anyone still on commit/push finishes now with circulating help. Everyone already through does the "it synced" check - open GitHub Desktop, confirm yesterday's push is visible on github.com (teaches the remote exists without costing setup time) - then helps a peer.
3. Roll-A-Ball download for finishers (10 min, self-paced, no whole-class walkthrough): students who pushed click the Roll-A-Ball assignment in Classmoji, accept it (check email for the org invite), clone with GitHub Desktop, and note the folder location. Warn the room: this repo is MUCH bigger than the test repo - it's a whole Unreal project, so the clone takes a few minutes. Kick it off and leave GitHub Desktop alone while it runs.
4. Independent tail (5 min): slow lane keeps working the GitHub cycle at its own pace; finishers poke at the cloned folder and find RollABall_Start.uproject - see it, don't open it. Unreal opens inside Video 01 tomorrow, follow-along.
5. Exit ticket (5 min)

## Exit ticket

1. What's the last step you finished today: test assignment pushed, Roll-A-Ball accepted, Roll-A-Ball cloned, or found the .uproject?
2. If you cloned Roll-A-Ball: where does the folder live on your computer - name where you put it. If not: where did your test repo clone to?
3. The Roll-A-Ball repo took minutes to download and the test repo took seconds. Why is a game project's folder so much bigger?

**Exit ticket mastery criteria:** Q1: any named step counts; the spread is the Wednesday Do Now's real baseline. Q2: a real folder path counts, even partial ("Documents/Game Programming Work/Roll-A-Ball"); "in GitHub Desktop" doesn't count - that's the app, not the location. Q3: any size-based reasoning counts (assets, textures, maps, sounds are big files) - it preps the Content Browser's scale before Video 01.

## Differentiation & Accommodations

- **Engagement:** the real project lands on their machine today, even for the slow lane's neighbors to see; the finishers' downloads are the room's visible momentum.
- **Representation:** the folder location is named twice - once during clone and once in the exit ticket (forced retrieval). The "repo is much bigger" warning prepares the wait instead of a frozen-looking GitHub Desktop.
- **Action & Expression:** finishers download without a gate; their pace is the room's ceiling, and the slow lane gets a full 20-minute spine on the cycle that matters for Monday's checkpoint math.
- **Accommodations:** anyone blocked at push gets a paired helper during the catch-up block. Students who did not get through Day 33's test assignment repeat the same cycle today - same skill, real work - and accept Roll-A-Ball tomorrow inside Video 01's block.
