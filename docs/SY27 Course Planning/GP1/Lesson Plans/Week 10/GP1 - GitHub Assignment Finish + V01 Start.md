# GP1 - GitHub Assignment Finish + V01 Start (Day 34)

Day 34 (A day, 48 min) - Finish the GitHub test assignment (commit/push whoever's left), then get the Roll-A-Ball starter project: accept, clone, open the .uproject in Unreal. Students who are already through start Video 01 on the template.

## Do Now

| # | Type | Question |
|---|---------|----------|
| 1 | Review | Yesterday you cloned a repo with GitHub Desktop. What does "clone" actually do to your computer? |
| 2 | Review | Your commit message yesterday described ONE change. Why write a specific message instead of "update"? |
| 3 | Preview | Today's repo is the actual game project you'll work in for weeks. What's a file type you'd expect inside a game project folder that you didn't see in yesterday's one-file test repo? |

## Structure

1. Do Now review (5 min)
2. Finish-the-test-assignment catch-up (10 min): anyone still on commit/push finishes now, circulating help. Everyone else opens GitHub Desktop and confirms yesterday's push is visible on github.com (the "it synced" check - fast, and it teaches the remote exists).
3. Roll-A-Ball starter walkthrough (8 min): accept the starter assignment link, clone, "Show in Finder", double-click the .uproject. Nick does each on the projector; Unreal takes a while to open, so the walkthrough starts the moment Unreal's loading bar starts - loading time is dead time otherwise.
4. Independent: everyone has the project open in Unreal by the ~80% mark (15 min, circulating). Fast students start Video 01's first steps; the video does not have to finish today.
5. Exit ticket (5 min)

## Agenda (A day, 48 min)

1. Do Now review (5 min)

3. Starter walkthrough (8 min, projector)
4. Independent open/start V01 (15 min, circulating)

**~80% checkpoint:** by end of item 4, every student has the Roll-A-Ball project open in Unreal. Students still blocked at clone get one-on-one in item 1 of tomorrow - the buffer lives in Day 35's independent block.

## Exit ticket

1. Show me (or write) where the Roll-A-Ball project lives on your computer - name the folder it cloned into.
2. What's the last step you finished today: test assignment pushed, starter cloned, project open, or Video 01 started?
3. In Video 01's first minutes, what does the finished game look like - name one thing you saw that your project doesn't have yet.

**Exit ticket mastery criteria:** Q1: a real folder path counts, even partial ("Documents/Game Programming Work/Roll-A-Ball"); "in GitHub Desktop" doesn't count - that's the app, not the location. Q2: any named step counts; the spread of answers is the Tuesday Do Now's real baseline. Q3: anything from the exemplar/trailer - rolling ball, camera, coins - counts as evidence they actually watched.

## Differentiation & Accommodations

- **Engagement:** the project opens today, in a class where every day to this point was setup - students see the real thing on day 2 of the project.
- **Representation:** "Show in Finder" is where file-system literacy gets scaffolded; Nick's walkthrough names the folder location twice, once during clone and once in the exit ticket (forced retrieval).
- **Action & Expression:** fast students start Video 01 without a gate; their pace is the room's ceiling, and the slow lane still hits "project open" by the bell.
- **Accommodations:** anyone blocked at clone gets a paired helper during the independent block. Students who did not get through Day 33's test assignment repeat the cycle with the starter, not a separate makeup - same skill, real work.
