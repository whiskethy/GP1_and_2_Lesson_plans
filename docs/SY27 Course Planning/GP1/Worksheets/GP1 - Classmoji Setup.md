# Setting Up Classmoji (GP1)

Classmoji is where the GP1 assignments live. This is a one-time setup; after it you are ready for every assignment this quarter.

## Create your account

1. Go to **app.classmoji.io**
2. Sign up with your school email (@chicagotechacademy.org)
3. Verify your email when the confirmation arrives (check spam)

Use the same email you used for your GitHub account.

## Join the classroom

1. I post a join link on Google Classroom
2. Click it. If it asks you to log in to Classmoji, log in first
3. You'll land in the **GP1 SY27** classroom

## Accept an assignment

0. Before you accept: open **GitHub Desktop** and sign in with the GitHub account you made (or already have). That is the account the repo will belong to.
1. In Classmoji, click into the assignment (the first one is the GitHub Test)
2. Classmoji creates your own copy of the assignment repo on GitHub under the ChicagoTechAcademy account
3. Check your email (spam too) for the org invite from GitHub and accept it. You need this before you can clone
4. Your repo link will look like `https://github.com/ChicagoTechAcademy/github-test-YOUR-USERNAME`

After you accept, follow the GitHub steps on the assignment or in class to clone it and start.
