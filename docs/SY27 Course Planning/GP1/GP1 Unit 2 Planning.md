### Driving Question

What does a game engine actually do, and how does game data become what you see on screen?

### Unit Narrative

A short unit that bridges the hardware foundations of Unit 1 and the editor work in Unit 3. Students learn what a game engine is and why developers use one instead of building from scratch, then trace the rendering pipeline from game data to pixels. The Unit 1 quiz lands in this week (Day 10) because it's a natural transition point before the editor opens.

### Enduring Understandings

1. A game engine is an abstraction layer: it handles rendering, physics, input, and asset management so developers don't have to build those systems from scratch.
2. The render loop (input → update → render) is the heartbeat of every game. Understanding it is prerequisite for troubleshooting in the Unreal editor.
