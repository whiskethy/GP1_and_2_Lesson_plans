# GP1 Unit 1: Data Under the Hood

## Unit Overview

| | |
|---|---|
| **Course** | Game Programming 1 |
| **School Year** | SY27 |
| **Teacher** | Gutierrez |
| **Grades** | 11/12 |

| **Unit Title** | Data Under the Hood |
| **Meetings** | 8 instruction (Days 1–8, W01–W02) + 1 quiz (Day 10, W03) |

### Driving Question

What's actually happening inside the machine when a game runs?

### Unit Narrative

The "how does the machine actually work" unit. Parts of a computer, file systems, what happens when a program runs, binary and hex, data types. No computers needed, and that's on purpose: we build the foundation first so the editor onboarding in Unit 3 isn't a scramble. The unit closes with reading real documentation and pulling out what matters, because reading technical material is the skill the rest of the year leans on.

### Enduring Understandings

1. Everything a computer does comes down to numbers. Binary and hex are just place value in a different base.
2. A program is instructions that get translated into something the machine can run.
3. Reading technical material is a skill you build, not a talent you have.
