# GP2 Q1 Day 5 — Anatomy of a C++ Program

**Date:** Mon 8/31 · **Unit:** 1 · **Chunk:** 5
**Planning Sheet:** [Week of 8/31](https://docs.google.com/spreadsheets/d/1BAraM0o0eLd7zR2-72g7UeiI0KIG54fnvjsCVU_h5sk/edit)

## Learning Target

Identify and explain the parts of a C++ program (#include, main, cout, namespaces, semicolons). Understand data types, arithmetic operators, and basic I/O (cin/cout).

**Standards:** CSTA 3A-AP-13 · ACT WME 402, CLR 401

**Performance Task Connection:** Understanding program structure and data types is prerequisite for the Code Read trace (Chunk 15/16). Data types are the foundation for every variable students will declare.

## Exit Ticket

1. What does `#include <iostream>` do?
2. Name three C++ data types and give an example value for each.
3. What does `std::cout << "Hello" << std::endl;` do, line by line?

**Mastery Criteria:** Correctly identifies all parts of a C++ program. Can name at least three data types with examples. Can trace a simple cout/cin program.
