# GP2 Q1 Day 7 — Intro to C++ Practice Problems

**Date:** Wed 9/2 · **Unit:** 1 · **Chunk:** 6
**Planning Sheet:** [Week of 8/31](https://docs.google.com/spreadsheets/d/1BAraM0o0eLd7zR2-72g7UeiI0KIG54fnvjsCVU_h5sk/edit)

## Learning Target

Identify and fix syntax errors in C++ code based on the rules learned so far.

**Standards:** CSTA 3A-AP-16 · ACT WME 402

**Performance Task Connection:** Syntax fixing is the skill that makes compiler errors readable. This practice directly supports Unit 2 Chunk 5 (reading compiler output) and every subsequent debugging day.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | What are the C++ syntax rules for semicolons, braces, and case sensitivity? |
| 2 | Review  | What data type would you use for a player's name? A score? |
| 3 | Preview | Today is all practice — fixing broken code. What kind of error do you think is the most common? |

## Exit Ticket

Fix 3 out of 5 broken programs and explain what was wrong in each.

**Mastery Criteria:** Identifies and fixes 3+ syntax errors with explanations.
