# GP2 Q1 Day 21 — Unit 1 Checkpoint

**Date:** Fri 10/2 · **Unit:** 1 · **Chunk:** 17
**Planning Sheet:** [Week of 9/28](https://docs.google.com/spreadsheets/d/1BAraM0o0eLd7zR2-72g7UeiI0KIG54fnvjsCVU_h5sk/edit)

## Learning Target

Demonstrate mastery of Unit 1 skills: write, debug, and commit C++ console programs using variables, functions, conditionals, and loops. Complete a Code Read trace on a short console program.

**Standards:** CSTA 3A-AP-13, 3A-AP-14, 3A-AP-15 · ACT WME 402, CLR 401, CLR 402

**Performance Task Connection:** This IS the Unit 1 deliverable. Students prove they can write, debug, and commit C++ console programs, and trace code they did not write.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | Write a for loop that prints the numbers 10 down to 1, one per line. |
| 2 | Review  | What is the difference between `=` and `==` in C++? |
| 3 | Preview | What should you do before you commit and push your checkpoint code? |

## Exit Ticket

1. Commit and push all checkpoint programs to GitHub.
2. Submit your Code Read trace on paper.

**Mastery Criteria:** Working console programs committed to GitHub that demonstrate variables, functions, conditionals, and loops. Code Read trace correctly identifies program output and explains each step.

## Agenda

1. Do Now review (3 min)
2. Checkpoint instructions and rubric review (5 min)
3. Independent checkpoint work (55 min)
4. Commit and push (5 min)
5. Code Read trace on paper (5 min) — if not embedded in the worksheet
6. Wrap up (4 min)

## What Changed

Originally Day 17 in the S&S. Pushed to Day 21 after the field trip cancellation and Nick's out-of-town absence (9/24-9/30). Checkpoint was moved after the review days so students had maximum practice before the deliverable.

## Differentiation & Accommodations

- **Engagement:** Checkpoint is the culmination of the unit — students prove what they've learned
- **Representation:** Rubric and exemplar programs available; C++ cheatsheet available as reference
- **Action & Expression:** Working programs submitted via GitHub; Code Read trace on paper
- **Accommodations:** Extended time for students with accommodations. Cheatsheet is allowed as reference, not as a substitute for writing code.
- **Student Voice:** Students choose which programs to attempt first within the checkpoint
