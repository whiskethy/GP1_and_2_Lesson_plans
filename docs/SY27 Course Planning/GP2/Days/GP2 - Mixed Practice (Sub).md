## Exit Ticket

1. What does this code print?
```cpp
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        cout << i << " ";
    }
}
```
2. Write a function called `isPositive` that takes an int parameter and returns true if the number is greater than 0, false otherwise.

**Mastery Criteria:** Correctly traces a loop with a conditional inside. Writes a function with a boolean return type and conditional logic.
