# GP2 Q1 Day 18 — Loops Practice + Scope

> **Sub coverage.** Nick is out. Students watch the EdPuzzle video and complete the worksheet. The sub does not need content knowledge.

**Date:** Fri 9/25 · **Unit:** 1 · **Chunk:** 15

## Learning Target

Write for and while loops independently. Trace loop output. Explain variable scope and identify where a variable is accessible.

**Standards:** CSTA 3A-AP-15, 3A-AP-14 · ACT WME 402, CLR 401

**Performance Task Connection:** Loop fluency is required for the Roll-A-Ball capstone (game loop, iterating over pickups). Scope understanding prevents the most common C++ bug category (variable shadowing) in the checkpoint and all subsequent work.

## Exit Ticket

1. Write a for loop that prints all even numbers from 2 to 20.
2. What is the output of this code?
```cpp
for (int i = 5; i > 0; i--)
{
    cout << i << " ";
}
```
3. A variable declared inside a loop body is not accessible outside the loop. What is this concept called?

**Mastery Criteria:** Writes a correct for loop with a step pattern. Correctly traces countdown loop output. Identifies scope as the concept that limits variable accessibility.
