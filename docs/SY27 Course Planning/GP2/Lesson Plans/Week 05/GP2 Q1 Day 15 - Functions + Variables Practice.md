# GP2 Q1 Day 15 — Functions + Variables Practice

**Date:** Mon 9/21 · **Unit:** 1 · **Chunk:** 11 (functions + variables practice)

> **Practice day.** No new instruction. Functions were introduced on Day 14; the practice never happened because Classmoji broke partway through. Today students clone their Variables Practice repo through Classmoji (clone only — autograding is removed and does not work) and work the programs in Visual Studio.

## Learning Target

Write and call functions with parameters and return values, and declare variables with correct types, by completing the Variables Practice programs and pushing them to GitHub.

**Standards:** CSTA 3A-AP-13 (create prototypes that use algorithms to solve problems), 3A-CS-02 (use appropriate tools and abstractions in a development workflow) · ACT WME 402 (technical vocabulary), CLR 401 (close reading of text)

**Performance Task Connection:** Function fluency and variable declaration are the raw material of every program in this course. Students who cannot write a function with parameters cannot write the Roll-A-Ball movement code, and the Unit 1 Checkpoint assumes both are automatic.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | Write the four parts of a function — return type, name, parameters, body — using `int add(int a, int b)` as your example. |
| 2 | Review  | What is the difference between `void` and a function that returns an `int`? When would you use each? |
| 3 | Preview | A game stores a player's name, age, and score. What data type would you pick for each one, and why? |

## Exit Ticket

1. Push your Variables Practice work to GitHub and paste your repo link.
2. Write a function called `double_score` that takes an `int` parameter and returns the value times two. Call it from `main()` and store the result in a variable you declared.
3. What data type would you use to store a player's health points, and why that one instead of `double`?

**Mastery Criteria:** Pushes a commit containing at least two working practice programs. Declares a function with a correct return type, name, and parameter list, calls it from main, and stores the result in a correctly typed variable. Justifies the int-over-double choice in terms of whole numbers and memory, not "because it works."
