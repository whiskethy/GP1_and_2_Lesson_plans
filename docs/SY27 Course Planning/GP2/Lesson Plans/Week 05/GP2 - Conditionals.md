# GP2 Q1 Day 15 — Conditionals

**Date:** Mon 9/21 · **Unit:** 1 · **Chunk:** 11

## Learning Target

Write conditional statements (if/else, else if) using comparison and logical operators.

**Standards:** CSTA 3A-AP-15 · ACT WME 402, CLR 401

**Performance Task Connection:** Conditionals are required for game logic (win/lose conditions, input branching) in every subsequent unit. The Roll-A-Ball capstone's input handling depends on if/else.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | How do you write an if statement in C++? What does the condition inside the parentheses do? |
| 2 | Review  | What is the difference between == and = in C++? |
| 3 | Preview | In Blueprint, you used branch nodes to make decisions. What do you think that looks like in C++? |

## Exit Ticket

1. Write an if/else statement that checks if a variable score is 100 or above. If true, print "Perfect!". Otherwise, print "Keep going!".
2. What does the && operator do in a conditional?

**Mastery Criteria:** Writes a correct if/else statement with proper syntax. Correctly uses comparison and logical operators.
