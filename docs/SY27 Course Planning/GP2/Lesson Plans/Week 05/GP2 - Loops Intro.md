# GP2 Q1 Day 17 — Loops Intro

**Date:** Wed 9/23 · **Unit:** 1 · **Chunk:** 14

## Learning Target

Write for loops and while loops, identifying the initialization, condition, and update parts of a for loop header.

**Standards:** CSTA 3A-AP-15 · ACT WME 402, CLR 401

**Performance Task Connection:** Loops are required for the Roll-A-Ball capstone (game loop, iteration over pickups). Every game runs on a loop. This is the last new idea before consolidation and the checkpoint.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | Write an if/else if/else that prints "A" for scores 90+, "B" for 80-89, "C" for 70-79, and "F" for anything below 70. |
| 2 | Review  | What does `&&` do in a conditional? What does `||` do? |
| 3 | Preview | Games run the same code 60 times per second. What C++ structure do you think makes that possible? |

## Exit Ticket

1. Write a for loop that prints the numbers 1 through 10, one per line.
2. What are the three parts inside the parentheses of a for loop, separated by semicolons? What does each one do?
3. When would you use a while loop instead of a for loop?

**Mastery Criteria:** Writes a correct for loop with proper syntax. Identifies all three parts of the for loop header. Distinguishes when to use for vs while.

## Agenda

1. Do Now review (5 min)
2. Loops lesson — for loop structure, for vs while (25 min)
3. Guided practice: write a for loop, trace output (10 min)
