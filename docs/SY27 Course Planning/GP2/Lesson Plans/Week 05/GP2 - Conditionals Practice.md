## Exit Ticket

1. Push your Variables Practice work to GitHub and paste your repo link.
2. Write a function called `double_score` that takes an `int` parameter and returns the value times two. Call it from `main()` and store the result in a variable you declared.
3. What data type would you use to store a player's health points, and why that one instead of `double`?

**Mastery Criteria:** Pushes a commit containing at least two working practice programs. Declares a function with a correct return type, name, and parameter list, calls it from main, and stores the result in a correctly typed variable. Justifies the int-over-double choice in terms of whole numbers and memory, not "because it works."
