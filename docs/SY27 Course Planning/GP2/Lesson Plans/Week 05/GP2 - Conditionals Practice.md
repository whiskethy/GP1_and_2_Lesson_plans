# GP2 Q1 Day 16 — Conditionals Practice

**Date:** Tue 9/22 · **Unit:** 1 · **Chunk:** 14
**Planning Sheet:** [Week of 9/21](https://docs.google.com/spreadsheets/d/1BAraM0o0eLd7zR2-72g7UeiI0KIG54fnvjsCVU_h5sk/edit)

## Learning Target

Write, debug, and commit conditional statements (if/else, else if) using comparison and logical operators.

**Standards:** CSTA 3A-AP-15 · ACT WME 402, CLR 401, S 404

**Performance Task Connection:** Conditionals are required for game logic in every subsequent unit. The Roll-A-Ball capstone's input handling depends on if/else. This practice day consolidates that skill before loops are introduced tomorrow.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | What does `else if` do that a separate `if` statement does not? |
| 2 | Review  | Write an if/else that checks if `health` is less than or equal to 0 and prints "Game Over" if true, "Still alive!" if false. |
| 3 | Preview | What happens if you need to check five different conditions in a row? How would you structure that? |

## Exit Ticket

1. Write a program that asks the user for a number and prints "Positive" if the number is greater than 0, "Negative" if less than 0, and "Zero" if it equals 0.
2. What is wrong with this code? Fix it.
```cpp
if (score = 100)
{
    cout << "Perfect!" << endl;
}
```

**Mastery Criteria:** Writes a correct if/else if/else chain with proper syntax. Identifies the `=` vs `==` bug.
