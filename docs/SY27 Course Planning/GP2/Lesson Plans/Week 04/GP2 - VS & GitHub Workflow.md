# GP2 Q1 Day 13 — VS & GitHub Workflow

**Date:** Tue 9/15 · **Unit:** 1 · **Chunk:** 10

## Learning Target

Use git add, commit, and push in Visual Studio to save and upload code. Clone a repo from Classmoji and push changes.

**Standards:** CSTA 3A-CS-02 · ACT WME 402, CLR 401

**Performance Task Connection:** Git workflow is required for every deliverable in the course. Students must be able to commit and push before writing functions.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | What is one theme or extension you installed in VS last week? |
| 2 | Review  | Why would it be important to save in-progress versions of your work? |
| 3 | Preview | What do you think the words "commit" and "push" mean when we talk about saving code? |

## Exit Ticket

1. Push a new commit to your repo.
2. What is the difference between git add, git commit, and git push?

**Mastery Criteria:** Successfully commits and pushes a change independently. Can explain the git workflow.

## Agenda

1. Do Now review (5 min)
2. Git workflow walkthrough — add, commit, push in VS (15 min)
3. Guided practice: make a change, commit, push (15 min)
4. Independent practice: modify code, commit, push (8 min)
5. Wrap up (5 min)

## What Changed

Originally VS & GitHub Workflow was Day 11 (C day, 72 min). Day 11 cancelled (field trip), then moved to Day 12 (sub day, A day, 48 min) as practice-only. This is now the teaching day for VS & GitHub Workflow, on Day 13.
