# GP2 Q1 Day 3 — Codedex Ch 1-2

**Date:** Wed 8/26 · **Unit:** 1 · **Chunk:** 3

## Learning Target

Write and run basic C++ code using Codédex. Understand Hello World and variable syntax.

**Standards:** CSTA 3A-AP-16 · ACT WME 402

**Performance Task Connection:** First hands-on C++ is prerequisite for all subsequent coding work. Students who cannot write and run a basic program cannot complete the Unit 1 checkpoint.

## Exit Ticket

Show your Codédex progress (screenshot). What does `cout` do?

**Mastery Criteria:** Can write a basic Hello World program and explain what cout does.
