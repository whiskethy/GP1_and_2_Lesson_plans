# GP2 Q1 Day 2 — Intro to CPP

**Date:** Tue 8/25 · **Unit:** 1 · **Chunk:** 2

## Learning Target

Explain what C++ is, why it's fast, and how a C++ file gets from source code to a running program.

**Standards:** CSTA 3A-CS-01 · ACT WME 402

**Performance Task Connection:** Understanding the build pipeline is prerequisite for reading compiler output in Unit 2 and for the Code Read deliverable. Students cannot troubleshoot what they cannot conceptually trace.

## Exit Ticket

1. What is the difference between a compiled and an interpreted language?
2. Name two reasons C++ is used for game development.

**Mastery Criteria:** Correctly explains compiled vs. interpreted and identifies 2+ reasons C++ is used in games.

## Agenda

1. Do Now review (5 min)
2. Intro to CPP lesson (20 min)
3. Guided practice: trace the build pipeline (15 min)
4. Wrap up (8 min)

## Differentiation & Accommodations

- **Engagement:** Students compare Blueprint to C++ pipeline
- **Representation:** Visual build pipeline diagram on board
- **Action & Expression:** Verbal or written exit ticket
- **Accommodations:** Printed guided notes
- **Student Voice:** Students share how Blueprint fits into the pipeline they just learned
