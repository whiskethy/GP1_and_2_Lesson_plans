# GP2 Q1 Day 10 — VS Setup

**Date:** Wed 9/9 · **Unit:** 1 · **Chunk:** 8

## What Actually Happened

Last-minute change from the original plan. Instead of git practice, the day became:

1. Opened Visual Studio for the first time
2. Set up themes and extensions (IDE customization)
3. Watched an EdPuzzle video walking through VS setup: [EdPuzzle](https://edpuzzle.com/media/66df07642911f28b0f4536e9)

Git workflow (add, commit, push) moved to Day 11 (Fri 9/12). Students will learn git using the variables practice programs as the content they commit.

## Learning Target

Complete VS/GitHub setup and practice commits and pushes independently.

**Standards:** CSTA 3A-CS-02 · ACT WME 402

**Performance Task Connection:** Continued VS setup and theme configuration. Tooling mastery is required for every subsequent coding day.
