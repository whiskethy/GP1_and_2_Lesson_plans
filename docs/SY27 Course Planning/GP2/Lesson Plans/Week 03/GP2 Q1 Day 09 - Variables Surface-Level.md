# GP2 Q1 Day 9 — Variables Surface-Level

**Date:** Tue 9/8 · **Unit:** 1 · **Chunk:** 7

## Learning Target

Declare, assign, and reassign variables with the correct data type. Understand naming rules and scope basics.

**Standards:** CSTA 3A-AP-16 · ACT WME 402, CLR 401

**Performance Task Connection:** Variables are prerequisite for every program in the course. The Roll-A-Ball capstone requires score, timer, and health variables. The Code Read deliverable requires identifying variable declarations and their types.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | You already used variables in Codédex (`int age = 25;`). What do you think happens in memory when you write that line? |
| 2 | Review  | What is the difference between an int and a float? |
| 3 | Preview | What happens if you declare a variable but never give it a value? |

## Exit Ticket

1. Declare an int, a float, and a string variable. Assign each a value and print all three.
2. What happens if you declare a variable but never assign it a value?

**Mastery Criteria:** Correctly declares and assigns variables with correct types. Can explain uninitialized variables.

## Agenda

1. Do Now review (5 min)
2. Variables surface-level lesson - slides 100-131 (20 min)
3. Finished Syntax Practice from previous class
4. Wrap up (8 min)

## Differentiation & Accommodations

- **Engagement:** Students choose variable names and values in practice exercises
- **Representation:** Slides with code examples, Codédex Build for hands-on
- **Action & Expression:** Verbal or written exit ticket
- **Accommodations:** Extended time; printed syntax reference sheet. Students who finish early can write an additional function with multiple parameters.
- **Student Voice:** Students choose what their variables store
