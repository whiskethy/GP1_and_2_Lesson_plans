Students submit Friday whatever tier of evidence they have actually finished; nothing still in flight is penalized. Working builds, committed code, demos. No standalone quiz.

**Date note:** this is Day 32, not Day 33 as the S&S originally wrote (holiday-blind math from 10/5; the day files are the correction layer). End of Q1. Q1 grades are due for teachers Wed 10/21, but Nick collects the school's grades and extends his own window to Fri 10/23, so CP1 grades inside the quarter's real deadline. The condition that buys the extension: **CP1 must grade in minutes.** Every tier below is presence-based, which keeps him to that promise by design, not discipline:

- Each tier is one screenshot present or absent; zero code reading to score.

- Grade-by exception: if a student's screenshot is ambiguous, the commit history settles it, and that is still minutes, not a session.

## Checkpoint evidence (tiered, per the locked design)

Tier the rubric by the video that teaches the skill; core tiers are attemptable with only Videos 01-04. Every tier is a small checkable evidence spec keyed to that block's build. Full credit for each submitted tier; missing tiers are visible, not penalized.

| Tier | Videos | Evidence spec |
|---|---|---|
| Core: project compiles | V01-V02 | Screenshot of a successful build from VS (green button / Ctrl+F5 run) with the project open, committed and pushed |
| Core: debug print evidence | V03 | Screenshot of on-screen Score print in a non-magenta color plus the Warning UE_LOG line (Day 26's challenge, still standing) |
| Core: loop runs | V05 | Screenshot of the for-loop yellow stack (or countdown), predicted out loud before the final run |
| Median: ball pawn assembled | V06 | Screenshot of the editor viewport with the ball visible and camera follow working at default values |
| Median: two tunables | V07 | Screenshot of the Details panel showing RollSpeed and JumpForce with at least one value changed from default |
| Median: error ritual | V04 | One before/after pair: the Error List with a real error on top, then the same list empty after the fix |
| Stretch: tuning in play | V07 | Short capture of the ball's movement with two different RollSpeed values, both shown changing behavior |

Submission: screenshots (and captures) to the Google Classroom assignment "GP2: Q1 Checkpoint 1" (numbered per the checkpoint naming convention), plus commit-and-push for anything that touched code. No paper, no saves handed over.
