## Learning Target

Review and consolidate conditionals and loops. Debug common loop errors (off-by-one, infinite loop, semicolon after for header).

**Standards:** CSTA 3A-AP-14, 3A-AP-15 · ACT WME 402, CLR 401

**Performance Task Connection:** This review directly prepares students for tomorrow's Unit 1 checkpoint. The checkpoint requires working programs that use conditionals and loops correctly — this day catches remaining misconceptions before the deliverable.

## Exit Ticket

1. Find and fix all three errors in this code:
```cpp
for (int i = 0; i < 10; i++) ;
{
    cout << i << endl;
}
```
2. Write a program that uses a for loop to print every multiple of 3 from 3 to 30 (3, 6, 9, ..., 30).

**Mastery Criteria:** Identifies the semicolon-after-for-header error and missing loop variable issue. Writes a for loop with a step pattern (`i += 3`).
