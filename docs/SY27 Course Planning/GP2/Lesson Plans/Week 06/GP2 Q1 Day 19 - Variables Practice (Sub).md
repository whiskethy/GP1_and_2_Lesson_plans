# GP2 Q1 Day 19 — Variables Practice (Sub)

**Date:** Tue 9/29 · **Unit:** 1 · **Chunks:** 11 (variables practice) + 13 (conditionals practice)

> **Sub coverage.** Nick is out. No new instruction. Two tasks: finish the Variables Practice programs, then start the Conditionals Practice problem set (writing programs in the repo students already have cloned). The sub does not need content knowledge.

## Learning Target

Declare variables with correct types and write conditional statements, by completing the Variables Practice programs and starting the Conditionals Practice problem set.

**Standards:** CSTA 3A-AP-13, 3A-AP-15, 3A-AP-17 · ACT WME 402, CLR 401

**Performance Task Connection:** Variables and conditionals are two of the four pillars the Unit 1 Checkpoint tests. Students who leave this week without both automatic will not be ready for the checkpoint when Nick returns.
