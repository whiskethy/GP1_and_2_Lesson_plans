# GP2 Q1 Day 6 — Data Types & Operators

**Date:** Tue 9/1 · **Unit:** 1 · **Chunk:** 5

## Learning Target

Use C++ data types (int, float, bool, char, string), arithmetic operators, and cout/cin for input and output.

**Standards:** CSTA 3A-AP-16 · ACT WME 402

**Performance Task Connection:** Data types and I/O are the foundation for every subsequent C++ program. Students need to understand cout/cin and type matching to write the checkpoint programs.

## Do Now

| # | Type    | Question |
|---|---------|----------|
| 1 | Review  | What does `#include <iostream>` do? |
| 2 | Review  | What is the difference between int and float? When would you use each? |
| 3 | Preview | In Blueprint you had Int, Float, Bool, and String. How do you think those are written in C++? |

## Exit Ticket

1. Declare an int, a float, and a string variable. Assign each a value and print all three.
2. What happens if you declare a variable but never assign it a value?

**Mastery Criteria:** Correctly declares and assigns variables with correct types. Can explain uninitialized variables.

## Agenda

1. Do Now review (5 min)
2. Data types + operators lesson (20 min)
3. Data types practice: Blueprint bridge table + exercises (15 min)
4. Wrap up (5 min)

## Differentiation & Accommodations

- **Engagement:** Students choose their own variable values
- **Representation:** Code examples on slides
- **Action & Expression:** Written code submission
- **Accommodations:** Printed syntax reference sheet
- **Student Voice:** Students choose what data to store in their variables
