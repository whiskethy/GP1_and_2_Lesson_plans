# GP2 GitHub & Classmoji Setup

Quick reference for student onboarding.

## Create your Classmoji account

1. Go to **app.classmoji.io**
2. Sign up with your school email (@chicagotechacademy.org)
3. Verify your email when the confirmation arrives

## Join the classroom

1. Your teacher posts a join link on Google Classroom
2. Click it. If you're not signed in to Classmoji, log in first
3. You'll see the GP2 classroom and your assignments

## Accept an assignment

1. In Classmoji, click into the assignment (Hello C++ or Variables Practice)
2. It creates your personal repo on GitHub and sends you an org invite
3. Check your email (including spam) for the ChicagoTechAcademy org invite from GitHub
4. Accept the org invite — you need this before you can clone

## After accepting

Follow the GitHub Onboarding guide for cloning and pushing with GitHub Desktop and Visual Studio.
