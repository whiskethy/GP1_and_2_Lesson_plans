# Standards

Reference copies of the standards frameworks relevant to Game Programming 1 & 2. Each file is structured so individual standards can be linked directly using anchor links (e.g., `[3A-AP-13](CSTA%20Standards.md#3a-ap-13)`).

## Notes in this folder

- [CSTA Standards](CSTA%20Standards.md) — CSTA K-12 Computer Science Standards (2017), 120 standards across Levels 1A-3B.
- [ISBE Computer Science Standards](ISBE%20Computer%20Science%20Standards.md) — Illinois Computer Science Standards (2022), 151 standards across Grades K-2 to 11-12.
- [ISTE Standards](ISTE%20Standards.md) — ISTE Standards (2024, v4.01), 26 standards / 100 indicators across Students, Educators, Education Leaders, and Coaches.
- [ACT CCRS Reading](CCRS-ReadingStandards.md) — ACT College & Career Readiness Standards for Reading, describing essential reading skills across score ranges 13-36.
- [ACT CCRS Mathematics](CCRS-MathematicsStandards.md) — ACT College & Career Readiness Standards for Mathematics, describing essential math skills across score ranges 13-36.
