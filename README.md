# GP1 & GP2 Lesson Plans

> **Live site:** [whiskethy.github.io/GP1_and_2_Lesson_plans](https://whiskethy.github.io/GP1_and_2_Lesson_plans/)

Lesson plans, scope & sequence, standards alignment, and day-by-day files for Game Programming 1 and 2 at Chicago Tech Academy.

## Courses

**Game Programming 1 (GP1)** - Blueprint-based game development in Unreal Engine. Students build a 2D platformer from scratch while learning how computers work, file systems, binary and hex, the rendering pipeline, and the Unreal Editor. Dual credit with a local college.

**Game Programming 2 (GP2)** - C++ game development. Students move from Blueprints into pure C++, building console programs first, then porting into Unreal. Covers data types, conditionals, loops, functions, and OOP entry points. Dual credit.

## What's here

- **Scope & Sequence** for each course
- **Q1 Calendars** with day-by-day scheduling
- **Lesson Plans** organized by week
- **Worksheets** and guided notes
- **Standards alignment** (CSTA 3A/3B, ISTE Students, ISBE, ACT/CCRS)
