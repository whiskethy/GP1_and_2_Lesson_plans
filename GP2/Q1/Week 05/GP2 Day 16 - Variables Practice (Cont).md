# GP2 Q1 Day 16 — Variables Practice (Continued)

**Date:** Tue 9/22 · **Unit:** 1 · **Chunk:** 11 (functions + variables practice, day 2)

> **Practice day, continued.** No new instruction. Students pick up the Variables Practice programs where they left off on Day 15 and finish them before conditionals start.

## Learning Target

Write and call functions with parameters and return values, and declare variables with correct types, by completing the Variables Practice programs and pushing them to GitHub.

**Standards:** CSTA 3A-AP-13, 3A-CS-02 · ACT WME 402, CLR 401

**Performance Task Connection:** Function fluency and variable declaration are the raw material of every program left in the course. Students who cannot write a function with parameters cannot write the Roll-A-Ball movement code, and the Unit 1 Checkpoint assumes both are automatic.

## Exit Ticket

1. Push your Variables Practice work to GitHub and paste your repo link.
2. Write a function called `double_score` that takes an `int` parameter and returns the value times two. Call it from `main()` and store the result in a variable you declared.
3. What data type would you use to store a player's health points, and why that one instead of `double`?

## Agenda

0. Enter class → open Visual Studio and your cloned Variables Practice repo. Continue where you left off.
1. Do Now review (5 min)

3. Independent practice — finish name-and-age, then rectangle-area, then temperature-converter. Commit and push each program as it works. Teacher circulates (30 min)

5. Exit Ticket (5 min)
6. Wrap up (2 min)

## Differentiation & Accommodations

- **Engagement:** Game-themed framing on the practice programs (scores, health, hitboxes). Early finishers write a function of their own design — a dice roll, a damage calculator.
- **Representation:** C++ cheatsheet on every screen; Day 14's worked example on the board; annotated starter code in the template repo.
- **Action & Expression:** Exit ticket written or verbal. Students can show a working program on screen instead of pasting a link.
- **Accommodations:** Extended time. Starter code in the template for students who need scaffolding. Pair programming for the guided program only.
- **Student Voice:** Students choose which independent program to tackle first (rectangle-area or temperature-converter) and design their own early-finisher function.
