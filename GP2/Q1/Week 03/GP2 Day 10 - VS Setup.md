# GP2 Q1 Day 10 — VS Setup

**Date:** Wed 9/9 · **Unit:** 1 · **Chunk:** 8

## Learning Target

Open Visual Studio for the first time and set it up: a theme, extensions, and a walkthrough of the editor.

**Standards:** CSTA 3A-CS-02 · ACT WME 402

**Performance Task Connection:** Visual Studio is where every C++ program in the course gets written. Tooling mastery is required for every subsequent coding day.

## Exit Ticket

1. What theme or extension did you install in VS today? Why did you pick it?
2. What is one thing VS can do that you didn't know about before today?
