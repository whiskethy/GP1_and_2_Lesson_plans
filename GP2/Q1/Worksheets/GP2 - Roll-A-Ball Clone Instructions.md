# GP2 - Roll-A-Ball Clone Instructions (Classroom Post)

Google Classroom post for Day 24. Students follow the numbered steps during the Do Now and clone block while Video 01 plays.

---

Today we start the Roll-A-Ball in C++ project. First step: get your copy of the starter project.

**Before you start:** you need your Classmoji account and your GitHub Desktop login working. If either one is broken, fix that first: [[GP2 GitHub & Classmoji Setup]].

## Get your project

1. Open **app.classmoji.io** and log in with your school email.
2. Click into the **Roll-A-Ball** assignment. Classmoji creates your personal copy of the project on GitHub. This is YOUR repo.
3. Check your school email (including spam) for the ChicagoTechAcademy org invite from GitHub if you haven't accepted it already. You can't clone until you have.
4. Open **GitHub Desktop**. File → Clone Repository. Paste your repo URL (or pick it from the list).
5. Remember where it cloned. You'll need that folder every day for the rest of the quarter.

## Open it

6. In the folder you cloned, double-click **CPP_RollABall_Start.uproject**. It opens in Unreal Engine 5.8.3.
7. Look around: this is last year's Roll-A-Ball. Same floor, same ball, same pickups. All Blueprint. Notice there is **no Source folder**. That's about to change.

## Watch Video 01

8. The rest of today runs on EdPuzzle: Video 01 walks you through converting this project to C++. Follow along on your machine while you watch.

Stuck on a step for more than 5 minutes? Raise your hand. Don't sit quiet through this one, today's setup only happens once and everything else builds on it.
