# GP1 Day 34 - GitHub Test Assignment (Full Walkthrough)

Day 34 (A day, 48 min). The GitHub test assignment runs start to finish today, guided by the walkthrough: the Classmoji invitation email, sign-in, the ChicagoTechAcademy organization invite, the confirmation check, then accept, clone, the secret phrase, commit, and push. Finishers start the Roll-A-Ball download.

## Do Now

| # | Type | Question |
|---|------|----------|
| 1 | Review | In yesterday's GitHub demo, push and clone both talk to your repo. What is the difference: which one puts a copy on your computer, and which one sends your change up? |
| 2 | Review | Put the four steps of the cycle in order: accept, clone, commit, push. |
| 3 | Preview | The test repo holds one README file. Roll-A-Ball is a full Unreal project. What do you expect to be true about that download, and why? |

## Shared Block

| Field | Value |
|---|---|
| Learning target | Clear the Classmoji invitation and the organization invite, then run the full GitHub cycle hands-on on the test assignment: accept, clone, edit the README with the secret phrase, commit with a message, push, and verify the commit on github.com. |
| New concept | The GitHub cycle as a hands-on loop: accept creates your repo, clone downloads it, the change list proves the edit, commit labels it, push uploads it, and github.com shows the proof. Yesterday was slides; today is the loop run once by every pair of hands. |

| Rides on | Day 33's slides and demo; GitHub accounts created Thursday. The emails flow rides the invites that Classmoji and GitHub send when students join the org. |

## Structure

1. Do Now review (5 min)
2. Part 1, the emails, guided on the projector (10 min): students follow the walkthrough. Classmoji invitation: find it (spam included), accept, sign in with the school email. GitHub org invite: find the second email, accept, and check for the confirmation. Students stuck here raise hands early; nothing downstream works without the org.
3. Parts 2-5, the assignment (20 min, guided then independent): accept the GitHub Test assignment in Classmoji, open GitHub Desktop, clone from the URL, open README.md in VS Code, type the secret phrase written on the board, save, commit with a message that says what they did, push, and check the commit on github.com. Teacher runs each step on the projector and students do it right after; anyone moving cleanly goes to the worksheet and runs solo while the teacher circulates.
4. Finishers: Roll-A-Ball download (self-paced, no walkthrough): accept the Roll-A-Ball assignment in Classmoji, check email for the org invite if it comes late, clone, and note the folder. Warn the room before anyone starts: this repo is MUCH bigger than the test repo, it's a whole Unreal project, the clone takes minutes, and leaving GitHub Desktop alone while it runs is normal.
5. Exit ticket (5 min)

## Exit ticket

1. Two emails did two different jobs: what did the Classmoji invitation get you, and what did the GitHub organization invite get you?
2. Your test repo landed in a folder. Write as much of that folder's path as you remember.
3. What's the last step you finished today: emails, accept, clone, secret phrase, commit, or push?

## Differentiation & Accommodations

- **Engagement:** the proof is real and immediate - your own commit on a public-looking github.com page - and finishers earn the real project the same day.
- **Representation:** the walkthrough is on the projector and in every student's hands as the worksheet; the change-list pane in GitHub Desktop is shown mid-flow so the abstract "commit" lands against a real visual.
- **Action & Expression:** students who push early help a peer clone; the fastest way to cement the cycle is watching someone else trip on it.
- **Accommodations:** students still missing an email after Part 1 pair with a neighbor whose inbox has theirs, then rejoin. Anyone blocked at accept gets one-on-one during the guided run; nobody goes home broken, and whatever step they reached finishes in tomorrow's catch-up inside Video 01's block.
