# Setting Up GitHub for GP1

You'll turn in every assignment in this class through GitHub. This guide walks you through the whole thing from wherever you are right now: the invitation, the organization, the assignment, the clone, the edit, the push.

**You only do Part 1 once.** After that, every assignment is the same loop: accept, clone, edit, commit, push.

---

## Part 1: The Emails

### Step 1 - Find the invitation from Classmoji

Open your school email and look for the invitation from Classmoji. Check spam too. It does show up there.

1. Click the link in the email
2. Accept the invitation
3. Sign in with your school email (your @chicagotechacademy.org address) when Classmoji asks

### Step 2 - Get into the organization

GitHub sent you a second email. It's an invitation to the **ChicagoTechAcademy** organization, the group your class repos live in. Check your email again, spam included.

1. Open the org invite from GitHub
2. Click **Accept**

You need to be in the org before you can grab your own copy of any assignment repo.

### Step 3 - Confirm both went through

One last email check. You should have, in some order: the Classmoji invitation accepted, the org invite accepted, and a confirmation for each. Signed in to Classmoji, you should see the GP1 classroom with your assignments listed.

If either invite is missing, you're not blocked. Raise your hand, or check spam one more time.

---

## Part 2: Accept the Assignment

### Step 4 - Open the GitHub Test assignment

In Classmoji, click into **GitHub Test: Clone, Edit, Commit, Push**.

When you click into the assignment, Classmoji creates your personal copy of the starter repo. Your repo URL will look like:

`https://github.com/ChicagoTechAcademy/github-test-YOUR-USERNAME`

You can copy that URL from the assignment page in Classmoji when you need it.

---

## Part 3: Clone the Repo to Your Computer

### Step 5 - Open GitHub Desktop

Open **GitHub Desktop**. If it asks you to sign in, use the same GitHub account you made last week.

### Step 6 - Clone your repo

1. **File → Clone Repository**
2. Click the **URL** tab
3. Paste your repo URL
4. Pick a folder you'll remember (like a `GP1` folder on your Desktop)
5. Click **Clone**

GitHub Desktop downloads the repo to that folder. One file in it: `README.md`.

---

## Part 4: Make Your Change

### Step 7 - Open the folder in VS Code

In GitHub Desktop, click **Open in Visual Studio Code** (or open VS Code yourself and go to **File → Open Folder**, then pick the folder you cloned into).

Double-click `README.md` to open it.

### Step 8 - Add one line

Read the README. It asks you to add one line: the **secret phrase written on the board**.

Type that phrase on a new line. Nothing else. Do not put your name, your address, or anything else personal about you in the file. Save.

---

## Part 5: Commit and Push

### Step 9 - Commit your change

Go back to **GitHub Desktop**. You should see `README.md` in the change list on the left. That's the pane that proves something actually changed.

1. Check the box next to `README.md`
2. Type a commit message that says what you did, like `add the secret phrase`
3. Click **Commit to main**

A commit is a save with a label, on your computer. The push is what leaves it.

### Step 10 - Push

Click **Push origin** at the top. Your commit uploads to your repo on github.com.

Open the repo page (or click **View on GitHub** in GitHub Desktop) and look for your commit with your message at the top of the file history. That's the whole assignment done.

### Step 11 - Check in on Classmoji

Back on the assignment page in Classmoji, your repo is linked next to your name. If your pushed commit is showing on github.com and the repo is claimed, you're done.

---

## Quick Reference: The Cycle

After this test, every assignment in this class is the same four steps:

1. **Accept** - click the assignment in Classmoji, get your repo
2. **Clone** - GitHub Desktop → File → Clone Repository → paste the URL
3. **Edit** - VS Code, make your change, save
4. **Push** - GitHub Desktop → commit → Push origin

Then check it landed. Repeat when you need to.
